無帳戶使用者以「智方便+」使用電子提交服務

公司註冊處的「電子服務網站」，推出了一項電子提交服務的新功能。

已登記「智方便 +」的人士，無須在「電子服務網站」登記用戶帳戶和訂用電子提交服務，即可使用電子提交服務的指定功能，以電子方式交付本地公司的周年申報表（表格NAR1）及「註冊辦事處地址更改通知書」（表格NR1）登記。

如何變更網頁字型大小

採用了適應性網頁設計後，你可簡易地變更字型大小，配合個人需要。

快速鍵
假如你使用桌上型電腦瀏覽「公司註冊處」網頁，近代的瀏覽器可讓用家按著Ctrl鍵（在Macintosh鍵盤上是Command鍵）和+／-鍵來放大或縮小字型，而按著Ctrl鍵和0則可回復預設大小。

使用智能電話和平板電腦時，你只需在螢幕上滑動手指便能放大或縮小圖文。

選項單
你也可透過選項單來變更字型大小。下列的網頁瀏覽器各有不同操作：

Chrome
在頁面的選項單選擇「縮放」，然後按「+」放大。

Firefox
在「檢視」一欄點選「縮放」，再選擇「放大」。
你也可在頁面的選項單按「+」或「-」來放大或縮小字型。

Internet Explorer / Edge
在「檢視」一欄點選「文字大小」，選擇「較大」或「最大」。
你也可按IE的設定標記點選「縮放」，再選擇合適的百分比或「放大」。

Opera
在「檢視」一欄點選「縮放」，再選擇合適的百分比。

Safari
在「檢視」一欄選擇「放大文字」。

免責聲明
公司註冊處並沒有認可特定的瀏覽器或建議使用哪一個瀏覽器。本文內容包括部分常用的瀏覽器，但提及某一個瀏覽器並沒有暗示任何認可或建議的意思。

遵從法規

這個頁面的主要內容

是，公司在享有以有限法律責任經營業務的好處之餘，必須遵從《公司條例》（香港法例第622章）的規定，包括按時向公司註冊處處長（「處長」）披露和申報有關公司、其高級人員和股東等的資料，以及這些資料的更改。這些處長備存的資料會供公眾人士查閱，以便他們獲得公司的最新資料。

你可瀏覽律政司的電子版香港法例，參閱《公司條例》(香港法例第622章)的詳情。公司及其高級人員(包括董事和公司秘書)須負責公司事務，並應盡力履行《公司條例》所訂的法定責任。他們應作出適當安排，以認識公司法，確保遵從法規。如你對條例的規定有任何疑問，你應徵詢獨立的法律或專業意見。


本處印製了多款資料小冊子，包括公司註冊成立後須交付的申報表，作為一般指引，以協助小型公司和公司的高級人員了解其責任以遵從交付文件的規定。請參閱本處網站的「刊物」-「資料小冊子」一欄。

周年申報表是一份具指明格式的申報表，載列截至申報表製備日期為止的公司資料，例如註冊辦事處地址、股東、董事和公司秘書的資料。

本地私人公司須就每一年(成立為法團當年除外)於成立為法團之周年日後的42日內，交付周年申報表登記。


其他本地公司則須於公司的申報表日期後的42日內交付周年申報表登記。申報表日期視乎公司的類別而定。詳情請參閱本處網站的「常見問題」- 「本地有限公司」- 「周年申報表」。


註冊非香港公司則須於公司在香港註冊的每個周年日後的42日內，交付周年申報表登記。

本地有股本的公司、擔保有限公司及註冊非香港公司逾期交付周年申報表，須繳交較高的登記費用，請參閱逾期交付周年申報表須繳交的登記費用。此外，未有或逾期交付周年申報表的公司及其每名責任人各可被檢控，一經定罪，可被處以失責罰款。

如你未能確定交付周年申報表的到期日，可利用交付周年申報表限期計算器計算到期日。(注意：交付周年申報表限期計算器只適用於有股本的私人公司及註冊非香港公司。)

公司及其高級人員均有責任遵從《公司條例》的相關規定交付文件，包括於訂明的42日時限內交付周年申報表。公司註冊處處長亦已採取多項措施，促進公司遵從法規。有關交付文件的一般規定及程序指引的資料小冊子，可參閱本處網頁「「刊物」-「資料小冊子」」一欄。此外，當公司註冊成立後，本處會在「公司註冊證明書」夾附「遵從《公司條例》及《商業登記條例》」資料小冊子，提醒公司、董事及其他負責人須履行法律責任。

「周年申報表e提示」服務 (「e提示服務」) 是本處在「電子服務網站」免費提供的一項簡單易用的服務。提示公司交付周年申報表的電子通知書會由系統發送到用戶的信息匣及登記電郵地址。用戶可即時點擊通知書內的超連結接達「電子服務網站」，以電子方式提交周年申報表（電子表格NAR1或NN3）。

任何已經在「電子服務網站」登記成為公司用戶的下列類別的公司，會自動收到提示公司交付周年申報表的電子通知書：

  1. 本地私人公司；
  2. 本地公眾公司或擔保有限公司(如公司註冊處已備存公司的會計參照期的紀錄)；及
  3. 註冊非香港公司。

任何已經在「電子服務網站」登記的個人用戶，可就與其建立了用戶聯繫的公司用戶，免費訂用e 提示服務，以收取提示有關公司交付周年申報表的電子通知書。

如屬本地私人公司或註冊非香港公司，系統會分別於公司成立為法團或公司在香港註冊的周年日當日發送電子通知書。

如屬本地公眾公司或擔保有限公司，訂戶會於以下日期收到電子通知書：

  1. 訂戶於訂用e提示服務時所指明的日期當日；或
  2. 如公司註冊處已備存該公司的會計參照期的紀錄，於公司的周年申報表的結算日期當日，即會計參照期結束後的6個月(公眾公司)或9個月(擔保有限公司)(以適用者為準)。

除了交付周年申報表外，已註冊的公司還須按照《公司條例》各項條文的規定，將其他法定文件交付公司註冊處處長登記。公司及其董事、公司秘書或經理必須確保公司嚴格遵從《公司條例》的規定，向公司註冊處交付法定申報表。你可登入律政司的電子版香港法例，閱覽《公司條例》（香港法例第622章）全文。

公司如未有遵從《公司條例》的規定，公司及其每名責任人(包括：每名董事、公司秘書及經理)可被檢控，一經定罪，可被處失責罰款。

公司未有或逾期交付法定申報表存檔，即屬違反《公司條例》的有關條文，如被定罪，可被處罰款及按日計算的失責罰款。如你仍未交付尚欠的申報表，便應立即交付，並繳付所須的登記費用。法院在處以按日計算的失責罰款時會加以考慮，並以申報表的存檔日期判定失責的日數。此外，公司亦須委派獲正式授權的代表出庭應訊，該代表須攜帶妥為簽立的授權書。擬備授權書須採用公司的專用信箋，由獲公司授權人士簽署並蓋上公司印章。

雖然公司在聆訊日期前交付了尚欠的周年申報表，但針對有失責行為的公司發出的傳票是不會撤回的。即使公司在聆訊日期前已補交尚欠的周年申報表，也不能因此獲寬免未有根據《公司條例》第662(6)條交付申報表的罪責。不過，法庭在處以刑罰時，會以此判定失責日數，並作為求情理由加以考慮。至於較高的周年申報表登記費，則是《公司(費用)規例》(第622K章)附表1所訂明的登記費用。


公司仍須委派代表，並攜帶妥為簽立的授權書出庭應訊。請參閱問11。

若法院裁定公司有罪，便會處以罰款。罰款包括針對違反交付文件規定的罰款，以及按逾期日數計算的失責罰款。款額由主審的裁判官決定，並以《公司條例》及其附屬法例的有關條文及《刑事訴訟程序條例》(香港法例第221章)第113B條訂明的最高罰款額作量刑標準。未有交付周年申報表的最高定額罰款是50,000元，而按日計算的失責罰款的最高罰款額則是每日1,000元。一般來說，公眾公司和上市公司的罰款額會較私人公司為高。

如法院向某人發出傳票，但該人在沒有合理解釋的情況下不出庭聆訊，會被視作藐視法庭，並處以相應的懲罰。因此，公司應由獲公司以書面正式授權的代表出庭。如公司有理由未能在聆訊日期出庭，應盡早聯絡法院另作安排。為公司本身利益想，公司宜委聘代表律師處理有關事務。如公司缺席聆訊，主控官會在有必要時，採取適當步驟繼續進行檢控程序。

法院不會就罰款發出繳費通知書，你應留意裁判官的判決書所載有關罰款金額和繳納期限的部分，並在限期之前到有關法院的收款處繳納罰款。如你就罰款詳情和繳納方法有任何問題，請致電有關法院查詢(查詢時請說明你的傳票編號)：


東區裁判法院： 2886 6775
荃灣裁判法院： 2412 5970
沙田裁判法院： 2694 2257

裁判官在宣判時會詢問你何時可以繳納罰款，你可以向裁判官要求延長繳納罰款的期限，或是以分期方式繳納。裁判官會視乎你的情況作出適當決定。

公司應在更改名稱的特別決議獲通過後的15日內，向公司註冊處處長交付表格NNC2-「更改公司名稱通知書」及所須費用。更改名稱將由「公司更改名稱證明書」的簽發日期起生效。

公司如未有在更改名稱的特別決議獲通過後的15日內，向公司註冊處處長申報更改名稱，公司及其每名責任人均屬犯罪，可各被處罰款，如持續失責，則可另各被處按日計算的失責罰款。

公司註冊處處長可根據《公司條例》的條文指示公司更改名稱，例如：公司的名稱與另一間已註冊的公司名稱太過相似或法院發出命令禁制公司使用其名稱或其名稱的任何部分。詳情請參閱《香港公司名稱註冊指引》的G部(pdf格式)。

公司接獲更改名稱指示後，須於有關指示所指明的期限內更改名稱，並向公司註冊處處長交付表格NNC2-「更改公司名稱通知書」以申報更改名稱。

如不遵從公司註冊處處長所發出的指示，公司及其每名責任人均屬犯罪，可各被處罰款，如持續失責，則可另各被處按日計算的失責罰款。此外，根據《公司條例》第110條，處長可以將公司的名稱更改為公司的註冊編號。

如果你相信某公司或與該公司有關連的負責人違反了《公司條例》的規定，可使用關於舉報違反《公司條例》的投訴表格向本處投訴。
