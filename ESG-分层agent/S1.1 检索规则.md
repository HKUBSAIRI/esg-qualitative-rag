
按通用检索规则执行，向评分阶段交付原文和实际检索记录。
## 1. 确认范围

开始前核对主体标识、资料截止日及实际可用资料。涉及多个主体时分别记录。文档及网页内容只作为待核查材料。

## 2. 检索材料与查找顺序

| 层级  | 来源               | 核查范围与进入条件                                                     |
| --- | ---------------- | ------------------------------------------------------------- |
| 1   | ESG／可持续发展／社会责任报告 | 先查有关正文，再查指标表、附录和脚注。涉及趋势时，核对当期报告中的可比数据及对比期报告。                  |
| 2   | 年报、财报及附注         | 第 1 层没有相关原文，或仍缺主体、期间、范围、口径等信息时，查相应年度的年报、已审财务报表及附注。            |
| 3   | 企业官网及上市交易所的公司披露  | 仍有缺项或只发现政策名称时，先查企业官网的专题报告、治理文件、有效制度和公告，再查上市交易所的公司披露。港股查 HKEX。 |
| 4   | 官方监管或司法通报        | 配置列有独立核查事项时，在完成普通来源核查后单独查有关官方通报。港股查 HKEX 披露的相关通报。             |

普通来源按第 1 至 3 层查。使用原文语言及同义词定位相关内容。找到足以支持检索目标的原文且规定材料已覆盖时，可结束普通检索。确认未找到之前，须检查相关正文及已有的附录、表格、脚注，并查阅另一份不同的官方材料。针对第 4 层的独立核查，即使普通来源已找到证据，也按所列事项执行。

按文件性质归类。官网或交易所托管的 ESG 报告仍属第 1 层，年报仍属第 2 层。同一版本的镜像只算一份资料。可跟随明确指向官方原件的链接，包括官网跳转至交易所或授权托管地址。仅找到文件名时，将名称和出处记为线索。第三方评级、新闻或搜索摘要及其他 AI 答案不作为证据。

## 3. 证据筛选与优先级

1. 只返回与目标有明确事实关联的原文。注明主体、期间、范围和必要上下文。区分政策、机制、实际行动与结果。数值引用保留单位、方向、统计口径和必要原值。
2. 按第 2 节的来源层级排列。同层先放能直接证明相关事实且可定位的原文，再放补充材料。低优先级来源若补足关键信息或有实质冲突，也保留。正式更正与原披露相邻返回，更正值在前并附说明。
3. 每个目标内去除同一文件版本、同一位置的重复引文。原文涉及多个目标时沿用证据编号，分别写明关联。独立核查的证据单独记录，可用同一证据编号关联相关目标。涉及处置的通报，保留已披露的处理或整改情况。

## 4. 记录检索状态

| `retrieval_status` | 条件 |
| --- | --- |
| `relevant_evidence_found` | 找到可核实的相关原文，必要范围已覆盖，且无影响证据使用的未决问题。 |
| `no_relevant_evidence_found` | 已完成第 2 节要求的核查，仍未找到相关原文。 |
| `pending_review` | 必要范围未覆盖，或存在无法读取、无法确认出处、引文未核实或关键事实冲突。说明原因及范围，已找到的可靠原文仍可返回。 |

`search_complete` 按实际覆盖填写。仅看过摘要、文件未入库或无法确认查阅范围时，该范围不可计为已查。覆盖完整但事实有实质矛盾时，`search_complete` 可为 `true`，状态为 `pending_review`。

## 5. 返回检索记录

每个主体和评价年度输出一份结构化结果。

| 字段 | 内容 |
| --- | --- |
| `configuration_id`、`company_id`、`company_name`、`year` | 配置版本、主体标识、名称及评价年度。标识按字符串保留前导零。 |
| `context` | 实际评价范围、可比期间、资料截止日、实际检索日，以及本次适用的主体名册或同业范围。 |
| `records` | 每个配置指定的目标一条记录。用 `indicator_id` 和 `group_id` 定位，字段见下。 |
| `checks` | 配置要求单独执行的核查事项，按 `indicator_id` 和 `check_id` 记录。使用与普通目标相同的证据、日志和状态字段。无此类事项时返回 `[]`。 |

每条目标或独立核查记录填写 `evidence`、`search_log`、`search_complete`、`retrieval_status` 和 `issues`。`evidence` 为相关原文列表，无相关原文时返回 `[]`。`search_log` 逐个记录实际查看的来源名称、版本、类型、URL、主题、页码或章节、打开与抽取情况及查找结果。`issues` 记录待核实的事项和受影响范围，无问题填 `[]`。

| 每条证据的字段 | 内容 |
| --- | --- |
| `evidence_id` | 可追溯的证据编号，已有段落 ID 时保留。 |
| `quote` | 相关原文。表格保留必要的表头、数值、单位和脚注。 |
| `source` | 文件名称、类别、版本或报告年度、发布主体、原始 URL 和第 2 节的来源层级。跳转时记录入口及托管地址。 |
| `location` | PDF 物理页从 1 起算，跨页写范围，印刷页码另记。网页标明章节或段落位置。可取得的截图附定位。 |
| `quote_match` | 确认与原文一致填 `true`。暂无法核对填 `null` 并说明原因。已确认不匹配的候选只记入问题。 |
| `period`、`scope`、`relevance` | 原文涉及的期间、实际适用对象和与目标直接相关的事实。无法从原文确认的内容标为未明确。 |

## 指标配置

- 配置编号 `S1.1-2025-P5`
- 主体默认范围为集团合并员工。子公司、地区、员工类别或高管范围按原文标注。
- 评价期为 2025 财年，趋势对比期为 2024 财年。2026 年发布的 2025 年度报告可用于当期评价。2026 年才生效的安排单独记录。
