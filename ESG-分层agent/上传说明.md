# 材料来源分层分支：本地项目快照

本目录来自本地 `ESG-分层agent`，用于保存分层检索、取证、评分代码，以及运行配置、输入材料、检索索引、模型调用记录和输出结果。仓库原有文件保持不变。本次不包括同级的“共享向量库”项目。

## API 配置

`.env.example` 保留实际使用环境中的模型名及服务入口，真实 API 密钥替换为 `YOUR_API_KEY`。复制为本地 `.env` 后自行填入密钥，通过入口的 `--env-file` 参数传入。代码中的模型常量及运行 protocol 才是对应实验实际模型的依据，环境模板不覆盖代码固定选择。`config/` 目录保留解析器运行配置和材料策略。

## 输入、输出和数据

- `resources/`、`GT报外来源/`、`validation/`：未超过文件阈值的输入、辅助来源和验证材料。
- `runs/random10_20261127/materials/`：未超过阈值的原始报告；选择名单、材料登记和分类清单同时保留。
- `runs/local_material_rag/index/`：当前正式本地RAG的分公司、分来源层级索引（包括已有向量和段落），不重新调用 embedding API。
- `runs/full5_20261127/` 及其他运行目录：快照读取时实际存在的检索、评分、调用记录、检查点、对比报告和输入/输出。未完成、失败及待核验状态按原样保存，不把它们转换为完成状态。

本项目运行时仍可能产生新文件；这是逐文件读取的时间点快照，不是暂停所有进程后的事务快照。上传清单记载各文件 SHA-256；不承诺动态运行目录中所有文件处于同一毫秒状态。

## 排除项及复现限制

未上传单文件超过50 MiB的资料（包括约63 MiB的 `新S1.1GT 来源筛选.xlsx`）、embedding缓存、Python缓存、运行锁及重复中间产物（原始Docling JSON、旧随机10家索引、重复分层解析/关联副本等）。当前正式检索索引、代码和主要实验结果保留。

`上传清单.json` 列出本地文件与上传副本的校验值；经过密钥脱敏的文件会单独标记。`.env.example`、本说明、忽略规则及上传清单是导出过程中新增的发布辅助文件。

`未上传清单.json` 列出所有排除文件的相对路径、大小及原因。复现需要缺失的原始材料时，可按登记信息中的官方 URL 重新取得，或由本地原件补充；不能将“文件未上传”等同于“当时未查阅”。部分路径记录保留原始机器路径，换机器时需要通过相应CLI参数和config调整，不应把所有路径盲目替换为新位置。

## 校验

上传前对Python源码做语法检查，运行不调用外部模型的本地回归测试，并扫描导出副本中的已知API凭据及常见令牌格式。API请求测试和完整评分流程不在发布时重新执行，避免额外计费及改变实验结果。
