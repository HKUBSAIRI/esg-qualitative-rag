無帳戶使用者以「智方便+」使用電子提交服務

公司註冊處的「電子服務網站」，推出了一項電子提交服務的新功能。

已登記「智方便 +」的人士，無須在「電子服務網站」登記用戶帳戶和訂用電子提交服務，即可使用電子提交服務的指定功能，以電子方式交付本地公司的周年申報表（表格NAR1）及「註冊辦事處地址更改通知書」（表格NR1）登記。

如何變更網頁字型大小

採用了適應性網頁設計後，你可簡易地變更字型大小，配合個人需要。

快速鍵
假如你使用桌上型電腦瀏覽「公司註冊處」網頁，近代的瀏覽器可讓用家按著Ctrl鍵（在Macintosh鍵盤上是Command鍵）和+／-鍵來放大或縮小字型，而按著Ctrl鍵和0則可回復預設大小。

使用智能電話和平板電腦時，你只需在螢幕上滑動手指便能放大或縮小圖文。

選項單
你也可透過選項單來變更字型大小。下列的網頁瀏覽器各有不同操作：

Chrome
在頁面的選項單選擇「縮放」，然後按「+」放大。

Firefox
在「檢視」一欄點選「縮放」，再選擇「放大」。
你也可在頁面的選項單按「+」或「-」來放大或縮小字型。

Internet Explorer / Edge
在「檢視」一欄點選「文字大小」，選擇「較大」或「最大」。
你也可按IE的設定標記點選「縮放」，再選擇合適的百分比或「放大」。

Opera
在「檢視」一欄點選「縮放」，再選擇合適的百分比。

Safari
在「檢視」一欄選擇「放大文字」。

免責聲明
公司註冊處並沒有認可特定的瀏覽器或建議使用哪一個瀏覽器。本文內容包括部分常用的瀏覽器，但提及某一個瀏覽器並沒有暗示任何認可或建議的意思。

如何取得公司資料?

這個頁面的主要內容
公眾查冊服務
  1. 查閱公司資料


  2. 我們提供查閱根據下列條例註冊的公司及法團的資料的服務：

    • 《公司條例》
    • 《有限責任合夥條例》
    • 《有限合夥基金條例》
    • 《註冊受託人法團條例》
    • 《證券及期貨條例》(有關開放式基金型公司)
    • 其他法團註冊條例

    你可透過以下方式查閱備存在公司登記冊內的註冊公司現況資料及已登記文件的影像紀錄：

    • 本處的電子服務網站的電子查冊服務
    • 親身到香港金鐘道66號金鐘道政府合署13樓本處的電子服務中心

    你亦可訂購已登記文件及查冊報告的經核證副本 ,或申請「公司迄今仍註冊證書」及「公司註冊紀念證明書」。

  4. 放債人登記冊的電子查冊服務

    公司註冊處已於2023年12月27日推出全面翻新的「公司註冊處綜合資訊系統」，以及全新的「電子服務網站」(www.e-services.cr.gov.hk)。查冊人士可以電子方式，通過本處的「電子服務網站」使用電子查冊服務，查閱放債人登記冊及持牌放債人委任的第三方詳情。

    關於香港金鐘道66號金鐘道政府合署13樓放債人註冊辦事處提供的就持牌放債人已登記的詳情的紙本檔案的查冊服務，已於2023年12月22日（星期五）下午五時後終止。
