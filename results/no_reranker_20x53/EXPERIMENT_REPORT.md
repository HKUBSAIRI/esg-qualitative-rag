# ESG 定性指标无 Reranker 检索评测

## 1. 实验目标

在统一的 PDF 结构化语料上，评估不依赖 reranker 模型的混合 RAG 方法对 53 个 ESG 定性指标证据的召回能力。Ground Truth 只用于评测，不参与候选排序。

## 2. 数据规模

- 20 份 ESG 报告
- 53 个定性指标
- 1,060 个 PDF×指标检索任务
- 647 个有可映射 GT 的任务
- 1,244 条人工证据行
- 1,799 个证据组件，其中段落组件 1,395 个、结构化组件 404 个

检索语料来自 `esg-qualitative-pdf-parser` 生成的 `retrieval_chunks.jsonl`。本实验冻结并统一使用 P/L/T chunk ID 空间，避免不同检索路线读取不同的表格扩展单元。

## 3. 方法

```text
BM25 Top150 ─┐
             ├─ 候选并集 → 本地特征融合 → 通道保护 → Top50
Dense Top150 ┘
```

Dense 模型为 `qwen3.7-text-embedding`，向量维度为 1,024。最终排序融合归一化语义分、词法分、两个通道的排名分和指标 facet 命中分；不调用 reranker，不调用 LLM 判分。

通道保护包括：

1. 保留 BM25 前 10；
2. 保留 Dense 前 10；
3. 每个指标 facet 至少保留一个最高分候选；
4. 按综合分补齐 Top50。

## 5. 文件

- `summary.json`：冻结配置、运行统计与总体结果；
- `per_query.csv`：1,060 个任务的明细；
- `per_metric.csv`：53 个指标的聚合结果；
- `results/`：每个任务的完整 Top50 候选及各通道分数；
- `embedding_cache/`：冻结实验的向量缓存。

## 6. 版本说明

本目录对应 2026-10-15 的 `no_reranker_common_corpus_diagnostic` 全量运行，是当前统一语料版本。早期 2026-09-30 的结果曾读取额外的表格行分组单元，与当前 `retrieval_chunks.jsonl` 契约不完全一致，因此未作为本仓库基线。
